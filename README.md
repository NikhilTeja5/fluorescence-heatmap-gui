Fluorescence Microscopy Particle Heatmap GUI

This Streamlit app generates enhanced fluorescence microscopy particle/molecule heatmaps from uploaded images.

Features

- Upload single images or ZIP files
- Generate original + heatmap strip panels
- Select heatmap color:
  - Blue
  - Cyan Blue
  - Yellow
  - Green
  - Red
  - Magenta
  - Fire
  - Inferno
  - Jet
- Adjust particle enhancement settings
- Download final high-resolution panel

Run locally

pip install -r requirements.txt
streamlit run app.py
